📚 Presença Digital

📌 Sobre o projeto

O Presença Digital é uma plataforma desenvolvida para facilitar o processo de envio, acompanhamento e gerenciamento de justificativas de ausência de alunos.

A proposta é substituir processos manuais por uma solução digital, permitindo que o aluno envie sua justificativa de forma rápida e acompanhe o andamento da solicitação.

---

🎯 Objetivo

O projeto tem como objetivo:

- Facilitar o envio de justificativas de ausência;
- Permitir o acompanhamento das solicitações;
- Organizar o histórico de justificativas;
- Facilitar a análise das solicitações pelos professores;
- Melhorar a comunicação entre alunos e instituição;
- Centralizar as informações em uma única plataforma.

---

👥 Público-alvo

A plataforma foi pensada principalmente para:

- 👨‍🎓 Alunos;
- 👨‍🏫 Professores;
- 🏢 Administradores da instituição.

🚀 Como executar o projeto

1. Clone o repositório

git clone https://github.com/Al-Moraes/Presenca-Digital.git

2. Entre na pasta do projeto

cd Presenca-Digital

3. Instale as dependências do Front-end

cd frontend
npm install

Depois, execute:

npm start

4. Execute o Back-end

Abra outro terminal e volte para a pasta principal:

cd ..
cd backend

Instale as dependências:

npm install

Depois execute:

npm run start:dev
